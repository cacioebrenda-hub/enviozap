Disparo Zap

Clique a clique, sem automação — sem risco de ban

1. Mensagem

Use {nome} no texto — o app troca automaticamente pelo nome de cada contato.

2. Contatos

Dica p/ extrair de grupo: abra o grupo → Dados do grupo → selecione e copie a lista de participantes → cole aqui direto. Funciona mesmo só com números soltos (sem nome) — cada número vira um contato "Contato XXXX" com os 4 últimos dígitos. O 55 do Brasil é adicionado automático se faltar.

3. Imagem (opcional)

O WhatsApp não permite anexar imagem automaticamente via link — isso é uma trava do próprio WhatsApp, não tem jeito de contornar. A imagem fica salva aqui só como lembrete visual pra você.
Se preencher, esse link entra sozinho no final de cada mensagem. O WhatsApp mostra um preview da imagem automaticamente pra quem recebe.
